## Mean, variance and covariance {#mean-variance-and-covariance .unnumbered}

$$\begin{align*}
    &X \sim U(0,1)\\
    &f_X(x) = p \\
    &E(X) = \int _{-\infty} ^{\infty} xf_X(x) \;dx = \int_0 ^1 xp \;dx = \left[\frac{px^2}{2}\right]^1_0 = \frac 12 \\ 
    &E(X^2) = \int _{-\infty} ^{\infty} x^2f_X(x) \;dx = \int_0 ^1 x^2p \;dx = \left[\frac{px^3}{3}\right]^1_0 = \frac 13 \\
    &\textit{Var}(X) = E(X^2) - (E(X))^2 = \frac 13 - \frac 14 = \frac 1{12}
\end{align*}$$

## $y = x^2$ {#y-x2 .unnumbered}

$$\begin{align*}
&X \sim U(0,1) \\
&f_X(x) =
\begin{cases}
1, & 0 \leq x \leq 1,\\
0, & \text{otherwise}.
\end{cases}\\
&y = g(x) = x^2\\
&g^{-1}(y) = \pm \sqrt y \\
&\frac{dy}{dx} = 2x\\
&f_Y(y) = \left. \sum ^K _{k=1} \frac{f_X(x)}{\left| \frac{dy}{dx}\right|} \right|_{x=x_k(y)} = \frac{f_X(\sqrt y)}{2\sqrt y} + \frac{f_X(-\sqrt y)}{2\sqrt y} = \frac{f_X(\sqrt y)}{2\sqrt y}\\
&f_Y(y) = \frac{f_X(\sqrt y)}{2\sqrt y} = \begin{cases}
\frac 1{2\sqrt y}, & 0 \leq y \leq 1,\\
0, & \text{otherwise}.
\end{cases}
\end{align*}$$

## $y = \ln(x) - \ln(1-x)$ {#y-lnx---ln1-x .unnumbered}

$$\begin{align*}

# Non-uniform random number generation

## Why the inverse CDF method works {#why-the-inverse-cdf-method-works .unnumbered}

This method works because the output of $F(Y)$ is constrained to the
range: $0\le F(Y) \le 1$ as it is a probability and so has to be between
0 and 1.

Thus the range of F(Y) lives in the same as the domain of the random
variable $X\sim U(0,1)$, i.e. constrained between 0 and 1.

Therefore if the inverse of $F$, $F^{-1}$, has the same domain as $X$.
Thus by passing a random input, $X$ as input to $F^{-1}$ we will obtain
a random value in the domain of $Y$.

Thus setting $y = F^{-1}(x)$ allows us to generate random numbers in the
distribution defined by $Y$, with CDF $F(y)$.

## CDF and inverse CDF of the exponential distribution {#cdf-and-inverse-cdf-of-the-exponential-distribution .unnumbered}

$$\begin{align*}
    &Y\sim \text{Exp}(1)\\
    &f_Y(y) = \begin{cases}e^{-y}& y\ge 0 \\ 0 & \text{otherwise}\end{cases}\\
    &F_Y(y) = \int _0 ^y e^{-y} \;dy =[-e^{-y}]_0^y = 1-e^{-y}\\
    &x = F_Y(y) \implies e^{-y} = 1-x\\
    &\therefore F^{-1}_Y(x) = -\ln \left(1-x\right)
\end{align*}$$

## Bernoulli and binomial random variables {#bernoulli-and-binomial-random-variables .unnumbered}

**Bernoulli Distribution**\
Uniform method generates a random decimal between 0 and 1 with all
values holding equal probability. However for a Bernoulli Variable we
want it to generate 1 with probability $p$ or 0 with probability $1-p$.

The probability that a number generated by uniform is less than or equal
to $p$ is in fact $p$. (i.e. $X \sim U(0,1);\; P(X≤p) = p$) Due to the
nature of the uniform distribution generating all values at the same
probability.

This means that if the uniform function of the LCG returns a number less
than or equal to $p$, we set bernolli to be a $1$. Otherwise we set it
to be a $0$.

**Binomial Distribution** A binomial distribution is simply the sum of
$n$ Bernolli distributions all with parameter $p$. Or mathmatically:
$$\begin{align*}
    &X \sim \text{Bernoulli}(p)\\
    &Y\sim B(n,p)\\
    &Y = \sum^n_{r=1} X_r
\end{align*}$$

Where $X_r$ are independent random Bernoulli Variables.

Thus to obtain a random binomial value, we simply have to call the
Bernoulli function with probability $p$, $n$ times and sum up the
values. This will then result in a random binomal value distributed as
$B(n,p)$.

    # Linear Congruential Generator (LCG) implementation in Python
    class LCG(object):
        def __init__(self, seed):
            # Initialize the LCG with a seed value
            self.__X = int(seed)

        def __call__(self):
            # Update the internal state using the LCG formula
            self.__X = (1664525 * self.__X + 1013904223) % 4294967296
            return self.__X

        def uniform(self):
            # Return a uniform random number in the range [0, 1)
            return self() / 4294967296

        def bernoulli(self, p):
            # Return a Bernoulli random variable with probability p
            
            # If the uniform random number is less than or equal to p, return 1 otherwise return 0
            # This is because the probability of getting a 1 is p,
            # and thus the fraction of decimals between 0 and 1 that are less than or equal to p = p
            # Thus resulting in a Bernoulli random variable with probability p
            return 1 if self.uniform() <= p else 0

        def binomial(self, n, p):
            # Return a Binomial random variable with parameters n and p

            # Initialize a variable to keep track of the total number of successes
            total = 0

            # Binomial is the sum of n independent Bernoulli random variables with probability p
            for i in range(n):
                total += self.bernoulli(p)

            # Return the total number of successes in n trials
            return total

## Neutral selection {#neutral-selection .unnumbered}

    # Import required libraries
    from LCG import LCG
    import numpy as np
    import matplotlib.pyplot as plt

    # Define a population class to handle the simulation over generations
    class Population:
        def __init__(self, N, Na, seed = 1234):

            # Population Size, N
            self.N = N

            # Number of individuals with gene A, Na
            self.Na = Na

            # Number of individuals with gene B, Nb
            self.Nb = N - Na

            # Generation/Time counter
            self.t = 0

            self.rng = LCG(seed)

        def next_generation(self):
            # Calculate the probability of selecting gene A
            p_A = self.Na / self.N

            # Generate the next generation using binomial distribution
            self.Na = self.rng.binomial(self.N, p_A)

            # Update the number of individuals with gene B
            self.Nb = self.N - self.Na

            # Increment the generation counter
            self.t += 1

        def simulate(self, generations, track_history=False):
            # Simulate the population for a given number of generations

            # If the current gneration counter is greater than or equal to the specified number of generations
            # (Which defines simulation length). Return the populaton size of gene A and gene B as a dictionary
            # Otherwise generate the next generation and recursivly call the simmulate function until the above critera is met
            if self.t >= generations:
                return {"Na": self.Na, "Nb" : self.Nb} if not track_history else self.history
            else:

                # If Track history is set to true store how population sizes change over time
                # If it is the first generation, initialize the history dictionary
                # Otherwise append current population sizes to the history dictionary
                if track_history == True and self.t == 0:
                    self.history = {"t" : [self.t], "Na": [self.Na], "Nb": [self.Nb]}
                elif track_history == True:
                    self.history["Na"].append(self.Na)
                    self.history["Nb"].append(self.Nb)
                    self.history["t"].append(self.t)

                # Generate the next generation and recursively call the simulate function
                self.next_generation()
                return self.simulate(generations, track_history)


    # Initialize a population with size N= 200 and Na = 100
    population = Population(N = 200, Na = 100, seed = 1234)

    # Simulate the population for 500 generations and track the history of population sizes
    generations = 500
    history = population.simulate(generations = generations, track_history = True)

    Na = history["Na"]
    Nb = history["Nb"]
    t = history["t"]

    plt.plot(t,Na, label = "Na")
    plt.plot(t,Nb, label = "Nb")
